# To-Do List Application

## About the Project
This is a simple To-Do List application made using HTML, CSS, and JavaScript. It helps users manage their daily tasks.

## Features
- Add new tasks.
- Mark tasks as completed by clicking on them.
- Delete tasks when they are no longer needed.
- Display all tasks in a list.

## Technologies Used
- HTML
- CSS
- JavaScript

## Project Structure
```text
To-Do-List/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run
1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Enter a task and click **Add Task**.
